- `projects/<project_name>/data/raw/`
- `projects/<project_name>/data/intermediate/`
- `projects/<project_name>/data/outputs/`
- `projects/<project_name>/data/external/`

Example:
- `projects/TR_LionsBurn/data/raw/SNAP/TR_LionsBurn_OS.csv`
